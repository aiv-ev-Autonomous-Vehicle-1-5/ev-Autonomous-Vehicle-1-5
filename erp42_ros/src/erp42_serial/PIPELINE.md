# erp42_serial

## Package 정보
- **패키지명**: erp42_serial
- **설명**: ERP42 시리얼 통신 브릿지 -- ROS2 메시지와 ERP42 시리얼 패킷 간 변환
- **노드**: `serial_bridge`

## 통신 사양

### 시리얼 프로토콜
- **Baud Rate**: 115200
- **데이터 비트**: 8N1

### 패킷 구조
| 항목 | 값 |
|---|---|
| TX 패킷 크기 | 14바이트 |
| RX 패킷 크기 | 18바이트 |
| 패킷 헤더 (STX) | `0x53`, `0x54`, `0x58` |
| 패킷 종료 (ETX) | `0x0D`, `0x0A` |
| 타이머 주기 | 20ms (50Hz) |

### 변환 계수
| 상수명 | 값 | 설명 |
|---|---|---|
| `MPS2BYTE` | 36.0 | m/s -> 바이트 변환 |
| `BYTE2MPS` | 0.02778 | 바이트 -> m/s 변환 |
| `RAD2BYTE` | -4068.0 | rad -> 바이트 변환 |
| `BYTE2RAD` | 0.000246 | 바이트 -> rad 변환 |

## 오도메트리
- **모델**: 자전거 모델 (Bicycle Model)
- **수식**: `angular_z = speed / wheelbase * tan(steering)`

## 파라미터

| 파라미터 | 기본값 | 단위 | 설명 |
|---|---|---|---|
| `port_path` | `/dev/ttyUSB0` | - | 시리얼 포트 경로 |
| `baud_rate` | 115200 | - | 시리얼 통신 속도 |
| `max_speed_mps` | 7.00 | m/s | 차량 최대 선속도 |
| `max_steering_deg` | 25.00 | deg | 차량 최대 조향각 |

## 차량 파라미터

| 파라미터 | 값 | 단위 | 설명 |
|---|---|---|---|
| `wheelbase` | 1.040 | m | 축거 (앞뒤 바퀴 간 거리) |
| `track_width` | 0.985 | m | 윤거 (좌우 바퀴 간 거리) |
