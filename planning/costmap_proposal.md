# 알고리즘 설명
- 라바콘, 차선은 현재 준비중인 대회 형식이라고 가정한다.
- 먼저 내 ego(차량) 중심(0,0)으로 +x: 5m, -x: 5m, +y: 5m, -y: 5m짜리 10x10(m) costmap 그리드를 생성한다.
- 라바콘, 차선을 이 코스트맵에 올림. 이제 이 코스트맵에는 라바콘, 차선, ego 밖에 없다.
- 라바콘과 차선을 모두 S극이라고 하고 코스트맵의 각각의 모든 픽셀에 S극 자기장의 세기를 기록한다.
- 각 픽셀 값의 범위는 0 ~ 100이다.
- 라바콘과 차선은 모두 S극 자석이지만 세기가 다르다. 라바콘 중심은 세기가 100, 차선은 세기가 50정도라고 하자 아무튼 자력은 라바콘 > 차선이다. 각 자석의 중심으로 멀어질수록 세기가 약해지며 픽셀에 기록된다. 각 픽셀에서 서로다른 s극에서 측정되는 자석의 세기들이 측정되는데 가장 강한 자석의 세기가 픽셀값을 override하게 된다.
- 이제 n극 입장에서 이 코스트맵을 봤을 때, 현재 ego지점(0,0)에서 heading 값(1,0)부터 시작하여 전방 180도 범위에서 s극 세기(픽셀값)가 가장 낮은 픽셀을 선택하여 이동한다. 
- heading이 바로 직전픽셀 -> 방금 이동한 픽셀 방향벡터로 업데이트 된다.
- 다시 heading 기준 전방 180도에서 가장 세기가 약한 픽셀을 선택하여 이동하며 앞의 과정을 반복한다.
- 이 궤적이 현재 frame에서 path가 되고 control에 이 path를 넘겨주어 차량에 control logic을 적용하여 이동 커맨드를 내린다.
